# HomeTunnel Add-ons

[HomeTunnel Client](hometunnel-client/README.md) provides private remote access to Home Assistant through your HomeTunnel account.

Add `https://github.com/HomeTunnel/ht-home-assistant-addon` to your Home Assistant Add-on Store repositories.
